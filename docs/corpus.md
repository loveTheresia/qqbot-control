# data/corpus —— 风格语料

还没有导入任何语料。需要时把文件放这里，再让主人执行：

```bash
/语料 导入 文件名.jsonl [来源]
```

支持两种格式：

**JSONL（推荐）**

```jsonl
{"text":"这波属实是绷不住了","source":"作品A","kind":"style","tags":["吐槽","游戏"]}
{"text":"先别急，让我捋捋","source":"群聊","kind":"style","tags":["安抚"]}
```

**TXT（一行一条）**

```text
这波属实是绷不住了
先别急，让我捋捋
```

导入时会：

1. 去掉空行/重复/脏话/链接；
2. 让模型生成 `meaning`（意思）、`trigger`（用法）、`examples`（例句）、`tags`（标签）；
3. 没把握时联网搜索再核实；
4. 只有 `verified=1` 的条目才会在群回复时被检索注入；
5. 每次最多注入 2 条、总字数有限，并明确“只学说法，不改人格”。

查看/反馈：

```bash
/语料
/语料 查 绷不住了
/语料 差 <编号>
/语料 忘 <编号>
```

不要直接删 `corpus` 表；用 `/语料 忘` 或 `status='retired'`。
