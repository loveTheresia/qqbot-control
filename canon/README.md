# Canon

每条一个 JSON 文件，建议字段：

```json
{
  "id": "work.example",
  "type": "work",
  "title": "《示例》",
  "source": "作者/来源",
  "summary": "一句话讲清它是什么。",
  "context": "背景。",
  "key_ideas": ["要点"],
  "misconceptions": ["常见误读"],
  "quotes": [{"text": "短引文", "verified": true}],
  "tags": ["文学"],
  "status": "draft"
}
```

只放摘要与短引文，不要整本上传；引文必须可核实。
